# Пилот: проверка связи и пробная торговля на Polymarket

Этот набор проверяет на вашем Mac в Сербии три вещи: (1) Polymarket не блокирует ваш адрес в интернете,
(2) официальный программный интерфейс (API) отвечает и быстро ли, (3) вы можете через официальную
библиотеку войти в свой счёт, выставить и снять крошечную заявку и, по желанию, сделать одну
настоящую покупку и продажу не дороже 2 долларов.

Ничего, кроме официальной библиотеки Polymarket, не ставится и не запускается. Все факты ниже взяты
из документации `docs.polymarket.com` и репозитория `github.com/Polymarket/py-sdk`, прочитаны
**2026-11-27**. Что в документации найти не удалось, помечено **«не подтверждено»**.

## Что в папке

| Файл | Что делает |
| - | - |
| `conn_check.py` | Проверка связи. Только стандартный Python, без ключа и без счёта. |
| `smoke.py` | Пробная торговля на официальной библиотеке. По умолчанию ничего не отправляет («сухой прогон»). |
| `requirements.txt` | Точные версии библиотек с контрольными суммами (sha256). |
| `out/` | Сюда пишется журнал без секретов и список заявок, выставленных скриптом. |

Жёсткие пределы зашиты в код, флагами их поднять нельзя:
пробная заявка — не больше **1 доллара** (цена × число акций); покупка в `roundtrip` — не больше
**2 долларов** вместе с оценкой комиссии. Заявка в `place` ставится «только мейкером» (post-only:
если бы она могла исполниться сразу, биржа её отклонит) и сама истекает примерно через 20 минут.

## Какие бывают счета и кошельки (по текущей документации)

Источник: https://docs.polymarket.com/trading/wallets-auth.md (2026-11-27).

- **Deposit Wallet** — основной «умный» кошелёк. Все кошельки счетов, созданные **4 мая 2026 года
  и позже**, — этого типа. Если вы заводили счёт недавно, у вас скорее всего он.
- **Proxy Wallet** — старый тип, создавался при входе на polymarket.com через Magic Link (почта) или Google.
- **Safe Wallet** — старый тип, создавался при входе через внешний кошелёк (MetaMask, Rabby).
- В самой библиотеке есть ещё тип **EOA** — обычный адрес без умного кошелька (когда адрес кошелька
  совпадает с адресом ключа). В тексте документации он описан только в списке типов.

Деньги на счёте — это **pUSD**, токен на сети Polygon, обеспеченный USDC 1:1, 6 знаков после запятой
(https://docs.polymarket.com/concepts/pusd.md, 2026-11-27).

## Откуда берутся ключ подписи и адрес кошелька («funder»)

**Адрес кошелька (funder, в скрипте — `PM_WALLET`).** Это адрес вашего счёта, его показывает меню
профиля на polymarket.com (https://docs.polymarket.com/trading/quickstart.md,
https://docs.polymarket.com/trading/wallets-auth.md#connect-your-account, 2026-11-27). Это не секрет:
он виден всем в блокчейне. Но он связывает счёт с вами, поэтому в репозиторий его не кладём.
В справочнике по переходу на новую библиотеку тот же адрес передаётся как `funder`
(https://docs.polymarket.com/migrate/clob-sdk-to-unified-sdk.md, 2026-11-27).

**Ключ подписи (signer).** Библиотека создаёт «подписанта» из закрытого ключа
(https://docs.polymarket.com/getting-started/python.md#secure-client, 2026-11-27). Документация
говорит, что это ключ, который управляет адресом подписанта (`<signer_address>` — «Polygon address
controlled by the signing private key», https://docs.polymarket.com/getting-started/api.md#authentication).
Адрес подписанта для вашего счёта показывается при создании ключа Relayer на polymarket.com:
Settings → API Keys → Relayer API Keys, поле **Signer Address**
(https://docs.polymarket.com/trading/wallets-auth.md#connect-your-account, 2026-11-27).

- **Как достать сам закрытый ключ счёта, заведённого через почту или Google на polymarket.com, —
  не подтверждено**: в документации разработчика этого шага нет. Не ищите это у сторонних сайтов
  и «ботов»: именно так крадут ключи.
- Если счёт заведён через MetaMask/Rabby (Safe Wallet), ключ подписи — это ключ этого внешнего кошелька
  (вывод из описания типов кошельков; прямой фразы в документации нет — **не подтверждено**).
- Документация описывает ещё два пути со свежим ключом, который вы создаёте сами:
  1. **Session Key** — отдельный ключ, которому владелец Deposit Wallet разрешает торговать на 180 дней;
     вывести деньги таким ключом нельзя. Чтобы его разрешить, нужен ключ владельца и ключ Relayer
     (https://docs.polymarket.com/trading/session-keys.md, 2026-11-27). Для пилота это лишний шаг, но
     для постоянного робота — самый безопасный вариант.
  2. **Новый счёт через Builder API key**: свежий ключ + ключ Builder из Settings → Builders, библиотека
     сама разворачивает Deposit Wallet (https://docs.polymarket.com/trading/wallets-auth.md#create-new-accounts,
     2026-11-27). Подходит ли этот путь для личного счёта, а не для «ваших пользователей», — **не подтверждено**.

**Проверка, что ключ и адрес подходят друг к другу.** `smoke.py auth` печатает адрес подписанта,
адрес кошелька, тип кошелька и роль ключа. Если роль `SESSION_KEY`, а Session Key вы не заводили, значит
ключ не от этого кошелька или `PM_WALLET` введён с ошибкой (так библиотека 0.20.1 трактует кошелёк,
который не выводится из ключа).

Совет: заведите для пилота **отдельный маленький счёт** с 5–10 pUSD, а не основной.

## Как хранить ключ

- Ключ — **никогда** в чат (ни сюда, ни кому-либо), в git, в журналы, на скриншоты, в заметки,
  в облачные папки (iCloud Drive, Dropbox).
- Только в файле, который читает лишь ваш пользователь:

```bash
mkdir -m 700 ~/.polymarket-pilot
umask 077
nano ~/.polymarket-pilot/key      # вставить одну строку: 64 шестнадцатеричных символа (можно с 0x), сохранить
chmod 600 ~/.polymarket-pilot/key
```

- `smoke.py` откажется работать, если файл или папка доступны группе или остальным, если файл не ваш
  или в нём не ровно один ключ. Содержимое файла скрипт не печатает никогда; секреты API (key,
  secret, passphrase) живут только в памяти и тоже вычищаются из вывода.
- Другое место файла: `export PM_KEY_FILE=/путь/к/файлу`.
- Документация в примерах держит ключ в переменной окружения; мы сознательно берём файл, чтобы ключ не
  попадал в историю оболочки.
- Включите FileVault (шифрование диска) на Mac.

## Установка

Нужен Python **3.11 или новее** для `smoke.py` (так требует пакет; https://github.com/Polymarket/py-sdk,
`pyproject.toml`, 2026-11-27). `conn_check.py` работает и на встроенном python3 macOS.
Проверьте: `python3 --version`. Если старее 3.11 — поставьте Python с python.org или через Homebrew.
Для установщика с python.org один раз запустите «Install Certificates.command» из папки Python в
«Программах», иначе будут ошибки сертификатов.

```bash
cd polymarket-lab/pilot
python3 -m venv .venv
.venv/bin/python -m pip install --require-hashes -r requirements.txt
.venv/bin/python -c "from polymarket.version import __version__ as v; print(v)"   # должно быть 0.20.1
```

Пакет: **`polymarket-client==0.20.1`** — официальный Python SDK
(https://docs.polymarket.com/getting-started/python.md, https://github.com/Polymarket/py-sdk,
2026-11-27). Старые клиенты `py-clob-client` не используются. Контрольная сумма колеса
`45109077df2b22aafb63879c4dbd292149de63bcadbefbc9686fd7cb71227997` совпадает с PyPI;
`--require-hashes` не даст поставить подменённый пакет.

VPN выключите: проверка блокировки и биржа смотрят на тот адрес, с которого идут запросы.

## Команды по порядку

Каждая команда `smoke.py` без `--live` ничего не отправляет от вашего имени: показывает, что сделала бы.

**0. Проверка связи** (без ключа):

```bash
python3 conn_check.py
```

Ждём: `blocked = False`, `country = RS`, задержку до REST (несколько десятков–сотен миллисекунд),
`handshake ok` и ненулевое число сообщений WebSocket за 15 секунд, итог `RESULT: OK (exit 0)`.
Коды выхода: 2 — адрес заблокирован, 3 — нет связи, 4 — REST работает, WebSocket нет.
Скрипт печатает и пару номеров токенов (token id) популярного рынка — их можно брать для `--market`.
IP-адрес не печатается и не сохраняется.
Источники: https://docs.polymarket.com/api-reference/geoblock.md (Сербии нет в списке ограниченных стран),
https://docs.polymarket.com/api-reference/wss/market.md (2026-11-27).

**1. Самопроверка без сети** (одноразовый ключ, ваш ключ не нужен):

```bash
.venv/bin/python smoke.py selftest
```

Ждём `selftest: ALL PASS`: отказы по правам файла, по пределам 1 и 2 доллара, по флагам, подпись заявки
проверена, ключа в журнале нет.

**2. Вход** (сначала сухо, потом по-настоящему):

```bash
export PM_WALLET=0x...    # адрес кошелька из меню профиля polymarket.com
.venv/bin/python smoke.py auth
.venv/bin/python smoke.py auth --live
```

`--live` создаёт или получает заново ключи API биржи подписью вашего ключа
(https://docs.polymarket.com/getting-started/api.md#authentication) и показывает: адрес подписанта,
адрес кошелька (должен совпасть с профилем), тип кошелька, баланс pUSD, разрешения (allowances) и
готовность разрешений на торговлю. Секреты не печатаются.
Если разрешения неполные — **не подтверждено**, выставляет ли их сайт сам; документация описывает
`setup_trading_approvals()` с ключом Relayer (https://docs.polymarket.com/trading/wallets-auth.md#execute-gasless-transactions).
Этот скрипт разрешения не трогает: напишите в лабораторию, добавим отдельный шаг.

**3. Пробная заявка, которая не исполнится:**

```bash
.venv/bin/python smoke.py place --market <token id>
.venv/bin/python smoke.py place --market <token id> --live
```

Выберите исход, у которого лучшая заявка на покупку (bid) от 0.10 до 0.90. Скрипт возьмёт
минимальный размер рынка (`min_order_size`, обычно 5 акций), цену не выше половины лучшего bid
и не ближе 5 шагов цены к нему, и откажется, если цена × размер больше 1 доллара. Заявка — покупка,
post-only, срок около 20 минут. Номер заявки записывается в `out/placed_orders.json`.
Источник: https://docs.polymarket.com/trading/place-orders.md (2026-11-27).

**4. Открытые заявки:**

```bash
.venv/bin/python smoke.py status --live
```

**5. Снять заявку** (снимаются только те, что выставил этот скрипт):

```bash
.venv/bin/python smoke.py cancel --live
```

Источник: https://docs.polymarket.com/trading/manage-orders.md (2026-11-27).

**6. Настоящая покупка и продажа (стоит денег):**

```bash
.venv/bin/python smoke.py roundtrip --market <token id> --live --yes-this-costs-money
```

Нужен исход с лучшей ценой продажи (ask) примерно до 0.30 и достаточным объёмом на ней. Скрипт
покупает чуть больше минимума (около 6 акций) не дороже лучшего ask, всего не больше 2 долларов с
комиссией, ждёт расчёта, продаёт полученные акции и печатает сделки, комиссии и сравнение с формулой
`комиссия = акции × ставка × p × (1 − p)` (тейкер платит, мейкер — нет; комиссия округляется до 5 знаков;
https://docs.polymarket.com/trading/fees.md, 2026-11-27). Ожидаемая цена опыта — спред плюс две
комиссии, обычно несколько центов. Если после покупки акций меньше минимума, продажа пропускается и
позиция остаётся (около 2 долларов).

Перед `place --live` и `roundtrip` скрипт сам ещё раз спрашивает официальную проверку блокировки и
ничего не отправляет, если адрес заблокирован.

## Что прислать в лабораторию

Журнал `out/smoke-ГГГГММДД.log`. В нём нет ключа и секретов API, **но есть адрес вашего кошелька**:
перед отправкой замените его, например, на `0xWALLET`. Папки `out/` и `.venv/` в git не попадают.

## Что не подтверждено

- Как выгрузить закрытый ключ счёта, созданного на polymarket.com через почту или Google.
- Ставит ли сайт разрешения на торговлю сам для нового Deposit Wallet.
- Подходит ли путь Builder API key для личного счёта.
- Минимальный размер заявки: страница размещения заявок называет `min_order_size` числом акций
  (пример: 5), а страница о рынках описывает `orderMinSize` как «minimum order size in USDC»
  (https://docs.polymarket.com/trading/place-orders.md, https://docs.polymarket.com/market-data/market-details.md).
  Скрипт берёт `min_order_size` из стакана как число акций.
- Что комиссия при покупке списывается в pUSD сверху суммы: так считает библиотека и так видно в
  данных (NOTES.md), но прямо в документации не сказано. `roundtrip` это измерит.
- Сербия не названа в документации разрешённой прямо; её просто нет в списке ограниченных стран.
  Окончательный ответ даёт `conn_check.py` с вашего адреса.

## Технические оговорки

- Сухой прогон строит клиента без сети с фиктивными ключами API и пользуется внутренними функциями
  библиотеки 0.20.1. Поэтому скрипт проверяет версию и откажется работать с другой.
- Сухой `place` читает публичный стакан и параметры рынка (это без входа), подписывает заявку вашим
  ключом локально и никуда её не отправляет.
- Скрипт не трогает разрешения, не выводит деньги, не создаёт Session Key и не ставит больше одной заявки за запуск.

## Живые микро-опыты со стоячими заявками (`exp_bids.py`)

Добавлено 2026-11-27. Подробная инструкция на русском — `EXPERIMENTS.md`: что измеряет каждый опыт из
`experiments/` (`tails`, `pairs`, `late-tail`), команды по порядку, как остановить (`touch ~/.polymarket-pilot/STOP`),
как читать `exp_bids.py report` и что прислать. Пределы зашиты в код: только покупка, только post-only GTD, не
больше 2.50 pUSD на заявку, 5 pUSD на окно, 15 pUSD и 300 заявок в сутки (UTC). Без `--live` ничего не отправляется.

**Погашение выигрыша (redeem).** Выигравшие акции превращаются в pUSD только после погашения; `exp_bids.py` его
**не делает**. По документации (https://docs.polymarket.com/trading/positions/manage.md, 2026-11-27): срока на
погашение нет; в SDK есть `redeem_positions(condition_id=...)`, для кошельков сайта (Deposit, Proxy, Safe) это
операция через Relayer и нужен ключ Relayer или Builder; для EOA — газ в POL. **Не подтверждено**: погашает ли
Polymarket выигрыши сам (в SDK есть уведомление `AutoRedeemedNotification` и разрешение «оператору автопогашения»,
но в тексте документации порядка нет) и как это выглядит на сайте. Подробности — в `EXPERIMENTS.md`.
