Официальная страница геоблокировки Polymarket (прочитана 27.11.2026) говорит:

1. Основные серверы биржи — AWS `eu-west-2` (Лондон). Ближайший регион без ограничений назван прямо:
   AWS `eu-west-1` (Ирландия). Для Ирландии и Нидерландов закрыт только сайт, API не ограничен.
2. Германия, Великобритания, Франция, Италия, Польша, США закрыты и на сайте, и в API (только закрытие позиций).
   Сербии и Финляндии в списках нет.
3. Есть официальная прямая колокация в `eu-west-2` после анкеты KYC/KYB — для маркет-мейкеров и частных
   трейдеров, торгующих за свой счёт.

Для тебя: постоянная часть (`live/`) должна переноситься на Linux-сервер без правок, с проверкой геоблокировки
при старте. Целевое место — AWS `eu-west-1`; когда покупать сервер, решает владелец. На сервере должен лежать
только торговый ключ (Session Key), не ключ владельца счёта.
