27 ноября 2026. L‑0 проверен на Mac. Следующий этап — двухчасовая запись публичных данных. Стартовая ревизия main `c7fac67`, рабочая ветка `astra/live`.

## Сделано и чем доказано

- В локальном окружении Python 3.12.13 команда `python3 -m pip install -e .` установила pmlab 0.1.0. Команда `python3 -m pytest -q tests` вывела `8 passed in 0.03s`.
- `live/.venv/bin/python3 -I live/doctor.py` получила BTC-стакан по REST и два начальных стакана и одно изменение по WebSocket. Официальная проверка вернула страну RS и blocked=false. Запросы времени к Apple и Cloudflare показали смещение +43,70 и +47,23 мс, оценку погрешности ±26,33 и ±25,44 мс. Это измерение часов при запуске.

## Дальше

Результат работы — запись и восстановление стакана, бумажный прогон btc5m_lockin, сухая проверка модуля заявок. Критерии и порядок L‑0 → L‑1 → L‑2 → L‑3 заданы владельцем. Данные пишутся в исключённый из git data/live/. Реальные операции требуют отдельного слова владельца и его присутствия. Деньги, платные подписки и ключи для этих проверок не используются. Приёмка по наблюдаемым результатам и независимой проверке. Если этап выходит за три часа, здесь фиксируется причина и работа переключается на доступный следующий этап.

Бюджет независимой проверки L‑0 — один читатель до 8 минут. На L‑1 цена пропущенного разрыва высока: до двух исполнителей на поиск рынков и проверку восстановления параллельно с разработкой записи, до 25 минут на человека, затем один независимый проверяющий до 15 минут. Денежный бюджет $0.
