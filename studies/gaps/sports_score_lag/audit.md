- Знак и направление: у 16 рынков с автоголами любимый токен по ленте вырос (до 0.57-0.999), то есть команда автогола
  в ESPN записана верно. Ничья: правило «разница после < разницы до» корректно. Финалы есть у всех 260 рынков.
- Время: всё в эпохе UTC, сплит 2026-11-24 00:00 UTC = 1795478400 проверен; время сделки = блок - 3 с; ESPN
  `wallclock` и лента на одной шкале (рынок реагирует раньше ESPN, а не позже на нереалистичные минуты).
- Комиссия: rate*p*(1-p) за акцию на входе, на выходе круга второй раз; ставка 0.05 (одна ставка 0.03 завышена,

  Зеркальное преобразование токенов верное (воспроизведено независимо).
- Кластеры по игре, сплит ранний/поздний не настраивался (протокол заморожен, числа не подгонялись).
- Утёкшие данные: P_pre и триггер используют только прошлое; P_post только в описательных таблицах. Триггер T

## Замечания

1. **Решающее правило не имеет мощности (средняя серьёзность).** Первичный критерий «удержание до исхода, t >= 2 по
   играм» при se 3.5-3.6 c на часть требует примерно +7-8 c; реальный эффект +3 c прошёл бы его в ~15% случаев.
   Вердикт «ни один из 12 не проходит» верен формально, но удержание не различает «0» и «+3». Круг и markout
   (+3.0, t 3.2) видят эффект, но он условный (знание гола). Что перезапустить: правило, где основной критерий —
   круг/markout, а удержание только диагностика (после новой записи в протокол, не правкой старой).
2. **Лента-без-гола проверена одним триггером (средняя).** Автор показал, что любой скачок на +3 c проигрывает,
   но не пробовал отличать гол от не-гола по ленте (размер скачка, одновременное движение второго рынка матча).
   Моя post-hoc разведка (5 вариантов, все посчитаны, не протокол): порог 8 c даёт круг +1.68 c (t 0.93, 398
   сделок, 75 игр; early +3.37, late +0.30); порог 3 c + движение второго рынка -0.23 (t -0.18); 5 c + второй
   рынок +1.02 (t 0.61). Все t < 1, значимости нет, но убыток «не-голов» (-2.6 c) почти исчезает при большом скачке.
   Это гипотеза для нового протокола, а не находка (множественные сравнения, пересечение сэмплов).
3. **Охват уже, чем заголовок (средняя).** Только футбол (мони-лайн) и NFL, одна неделя, поздняя часть NFL — 5 игр.
   Не смотрели теннис (сеты, брейки; вопрос владельца называет «выигранный сет»), NBA (там `secondsDelay` 0 по
   заметкам автора), NCAAF, киберспорт, а также рынки тоталов и «следующий гол». Фраза «спортивная задержка не
   стратегия выходных» распространена на то, чего не измеряли. Также не проверена собственная лента счёта
   Polymarket (в наборе `Houroux/polymarket-l2-history` есть на одной шкале времени): если она опережает ESPN,
   «нужна лента быстрее ESPN» перестаёт быть тупиком. Измерить пассивно, бесплатно.
4. Мелочи. Пул 0-1 с включает сам первый крупный свип (его VWAP ниже середины), поэтому 78% завышает «чужой
   захват», но недостижимый для медленного трейдера пул это не меняет. Триггер «d = 3 с от времени матча» для
   REST-опроса данных на деле позже (+2-3 с), для WebSocket корректен; T10 (круг +2.0, t 2.5) покрывает этот случай.
   Разница удержание ≈ 0 против markout +3.3 для T3 лежит в пределах 1.3 se удержания, но вес в пользу «часть
   markout — смещение контрольной цены» не дан; круг (реальные продажи) этого не опровергает и не подтверждает.
